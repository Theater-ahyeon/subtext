# Round 01 · MVP（v0.1.0-mvp）

日期：2026-08-31

## 本轮范围（最小可用）

| 模块 | 交付 |
|---|---|
| 人物档案 | 创建/删除/编辑，本地 `userData/habitat-data/`，JSON 原子写入 |
| 理解卡 | 四层 claims CRUD（认识层级 事实/推断/空白 × 来源 证据/用户陈述/AI推断 × 置信度）、动态状态层（可"翻篇"）、AI 从素材归纳初稿、注入卡片预览、卡片导出 JSON |
| 原话库 | 手动存证、删除；来源分类（聊天/朋友圈/现实反馈/其他） |
| 导入 | 粘贴文本自动解析 + 文件导入（json/jsonl/csv/txt）；兼容留痕 MemoTrace JSON、WeChatMsg CSV、QQ 时间戳 TXT、微信合并转发文本、通用 JSON 数组/JSONL；"我的昵称"标记本人 |
| 演练 | 场景模板（日常/约会/冷战/道歉/重要谈话/请求）+ 自定义；模拟开场与多轮对话；红线硬过滤（操控/打压类请求拒绝并转向"诚实表达"建议）；结束生成复盘报告（六观察指标 + 用户沟通复盘 + 下轮建议 + 现实验证清单） |
| 对照复盘 | 预判冻结（2~4 假设 + 概率 + 依据 + 验证方式 + 预期形态）→ 现实反馈对照（原话优先，同时存证）→ 差异分析（七类 verdict 逐层差异分析）→ 卡片最小修正（add/update/deprecate，旧值入 note 可回滚）→ 统计（Top1/Top2 命中率、闭环完成率） |
| 24 问 | 人物观察版题库（5 组 24 题）、抽象回答 AI 追问、跳过=暂未确定、中途小结、最终整合 → 勾选写入理解卡（用户陈述）；Q24 直接成为模拟防误读护栏（compileCard 注入） |
| 想多了解的 | 空白条目 + 访谈待确认 → "下次可以了解她什么"清单 |
| 设置 | Provider 切换（演示模式 / OpenAI 兼容）、连接测试、数据目录展示、红线提示 |

## 质量

- 测试 20/20 通过（`npm test`）：解析器 6、存储 2、提示词 5、流水线 6、安全 1。
- Electron 启动冒烟通过：窗口 `演练 · Rehearsal` 正常创建，无控制台错误。
- 安全基线：contextIsolation + 无 nodeIntegration + CSP（script-src 'self'）；渲染层全量 HTML 转义；LLM 输出经转义后受限渲染。
