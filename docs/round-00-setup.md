## 方法论落地映射（AIRP 人物生境写法 → 产品）

1. **生境卡四层** = 基础信息 / 生活结构 / 人物性情 / 场景表达；空白层不进卡（AIRP：可选项连同标签删去）。
2. **静态/动态分离**：易过期信息只进动态状态层，防止"关系倒退"。
3. **写倾向不写唯一答案**：归纳与心理假设强制倾向措辞（往往/容易/更愿意），禁"永远"，禁临床标签。
4. **证据可溯**：claim 必须挂证据编号 / 用户陈述 / AI 推断三种来源之一。
5. **预测-反馈-校准闭环**：预测单冻结 → 现实回流 → 差异归因（逐层）→ 卡片最小修正。
6. **失败模式 → 检测**：红线守卫（操控类请求硬过滤）、防复读/防脑补（归纳器规则 + 相似去重）。
7. **24问访谈**（外部方法论输入）：人物观察版改写，输出按"用户确定/高可能推论/待确认"三级写入。
