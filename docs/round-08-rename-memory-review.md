## 一、功能层审查（逐项攻击）

### 1. 事件记忆（episodic memory）

| 攻击点 | 结论 | 防线 |
|---|---|---|
| 记忆会不会悄悄联网？ | 不会静默发生 | Embedding 端在设置页显式配置（默认"跟随主模型"，非 openai/gemini/ollama 主模型时走本地词面）；服务商失败自动降级 `local:hash` 并在理解卡页如实标注"本地词面检索"，差异分析 toast 同样披露 |
| 同一场演练会不会重复记忆？ | 不会 | `memories.ledger` 按会话 id 记账，单测覆盖（重复复盘不重复记忆） |
| 记忆可以无中生有吗？ | 弱点已知 | mock/降级路径使用 `naiveEvents`（摘录首条用户消息与末条模拟回应），明确弱于 LLM 提取——代码注释已自证"明确弱于"，不冒充语义记忆 |
| 记忆能删除吗？ | 能 | 单删/清空/重建索引三件套；每条带来源引用（演练场次 / 证据 E# / 预判 id）；删除记忆不影响理解卡与证据 |
| 换 Embedding 模型会怎样？ | 已处理 | 维度不一致的旧向量跳过召回 + `stale` 标记提示重建；重建按钮一键重嵌 |
| 记忆库满了怎么办？ | 已知边界 | 2000 条上限，超出返回 full（UI 提示列入 P2） |

### 2. 扮演偏差（model-bias）——信用分配

| 攻击点 | 结论 | 防线 |
|---|---|---|
| LLM 会不会滥用 model-bias 逃避修卡？ | 有此风险，已设监控口径 | `modelBiased` 单列计数暴露在 stats；若占比异常偏高即为"归因逃避"信号（比例告警列入路线图）。prompt 侧限定"真实反应其实符合理解卡或预判"才可判 |
| model-bias 会不会污染命中率？ | 不会 | 不进命中率分母、不进 Brier，单列 `modelBiased`；UI 文案明确"扮演偏差不计入命中率" |
| 直接录入（无预判）会误判吗？ | 不会 | model-bias 判定仅在预测模式下开放（需要演练记录可回看） |

### 3. 学习率 α（δ·α 纪律）

| 攻击点 | 结论 | 防线 |
|---|---|---|
| 单次命中会不会把卡越推越满？ | 会大幅缓解 | hit α=0.15 / partial α=0.3：新增条目置信度 = 0.4+0.3α（hit 下 0.445，低于进卡阈值 0.3 之上但仍保守）；deprecate 下调 0.3×α |
| 撤销能完整恢复吗？ | 能 | deprecate 撤销走 prevConf 原值恢复（不依赖 α 反推）；update 撤销还原文本并清理备注段；α 写入 note 透明可审计 |
| α 表对用户可见吗？ | 可见 | 每次修卡的 note 带 `(α=0.8)` 字样，卡片编辑备注里可查 |

### 4. Brier 校准

| 攻击点 | 结论 | 防线 |
|---|---|---|
| 概率是 LLM 编的，Brier 有意义吗？ | 这正是做它的原因 | Brier 暴露的恰是"口头概率不可信"本身：持续 >0.25 即系统性过自信，UI 直接给出行动建议（预判整体调保守） |
| 口径偷偷换过吗？ | 已写明 | Top1 口径、outcome 编码（hit=1 / partial=0.5 / 其余=0）、旧数据无 topProb 跳过——注释与 UI 双处写明 |

### 5. 状态栏（HUD）

成长阶段（初见→同频）是启发式热度分，不是"亲密度评分"——面板底部固定红线文案"它是理解辅助，不是评判表"，防止把人物养成游戏化误读。

## 二、措辞层审查（更名迁移）

**全局清扫结果**：`生境` 在 src/web/docs/README/CHANGELOG/配置中残留 **0 处**；用户可见层的旧词（数字孪生/预测单/冻结/回流/归因/话题雷达/置信度）按命名审计方案一完成映射替换，且提示词层（prompts.js/llm.js mock 文案）同步改写——AI 输出不会再把旧称泄漏给用户（审查报告 C5 隐性泄漏通道已封）。

**抽查一致性**：导航八项（关系/理解卡/原话库/导入/24 问/彩排/对照复盘/设置）与各页标题、按钮、错误提示、toast、HUD 文案一致；无"彩排彩排""差异差异分析"类清扫叠词（已专项扫描清零）。

**刻意保留的兼容层（非残留，均有注释说明）**：
- 数据目录 `%APPDATA%/habitat-sandbox/`（C1：改名不迁移目录，老档案无感延续；main.js 显式 setPath 钉住）
- `window.habitat` 全局名与 `habitat-data` 子目录（C4：纯内部标识）
- 导出格式读取兼容旧 `habitat-sandbox-card`（C2：新导出为 `rehearsal-card`）
- 单元测试临时目录前缀 `habitat-test-*`（内部实现细节，永不见于用户）

**历史文档**：docs/round-00~07 为开发史，已同步完成术语清扫以便阅读，时间线叙事保留。
